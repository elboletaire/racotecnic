¿Cuántas veces has tenido que integrar una de tus aplicaciones web con <a rel="noopener nofollow" href="http://www.facebook.com" target="_blank">Facebook</a>? Y después de Facebook, tuviste que hacer la integración con <a rel="noopener nofollow" href="http://www.twitter.com" target="_blank">Twitter</a>, la de <a rel="noopener nofollow" href="http://www.linkedin.com" target="_blank">LinkedIn</a> y otras tantas más.

Con <a rel="noopener nofollow" href="http://www.gigya.com" target="_blank">Gigya</a> tienes una API unificada para la mayor parte de las redes sociales. En apenas media hora habrás integrado el login de tu página con Facebook, Twitter, LinkedIn, <a rel="noopener nofollow" href="http://www.openid.net/" target="_blank">OpenID</a>, <a rel="noopener nofollow" href="http://www.yahoo.com" target="_blank">Yahoo</a>, <a rel="noopener nofollow" href="http://www.myspace.com" target="_blank">MySpace</a> o cualquier otra de las redes sociales que puedes integrar con Gigya.

Para utilizarlo simplemente necesitas registrarte en su web y añadir aquellos servicios que quieras utilizar desde el panel de control:
